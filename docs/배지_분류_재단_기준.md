# 배지 컬렉션 분류와 완성선 기준

## 타입별 컬렉션

사용자가 지정한 프레임 기준으로 나눕니다. 서로 다른 타입의 같은 캐릭터는 별개 디자인으로 유지합니다.

| 타입 | 시각 기준 | 목록 |
| --- | --- | --- |
| 골드 | 금색 링, 클로버 보석 프레임 | 24종 |
| 스파클 | 은색 링, 하트 보석 프레임 | 24종 |
| 샤이닝 | 캐릭터 컬러 링과 원형 보석 프레임 | 24종 |

같은 타입 안에서 동일 캐릭터가 반복되는 8개 배치를 대조해 합쳤습니다. 손동작과 미세한 배치 차이를 별도 종류로 세지 않습니다. 제작 원본 80개 배치는 출처 기록에 보존하고, 실제 컬렉션·3D 선택 목록에는 72개 항목만 제공합니다.

## 3mm 인쇄 여분과 54mm 완성 지름

- 입력 기준: 완성 지름 54mm, 인쇄 여분은 각 방향 3mm. 따라서 논리적인 인쇄 영역 지름은 60mm입니다.
- 앞면: 프레임 중심을 기준으로 잡은 60mm 인쇄 영역의 왼쪽·오른쪽·위·아래에서 각각 정확히 3mm를 제외합니다. 임의의 픽셀 여백이나 이미지 객체의 바깥 경계를 완성선으로 사용하지 않습니다.
- PDF 좌표 환산: 1mm = 72/25.4pt, 각 방향 3mm = 약 8.503937pt. 완성 지름은 약 152.787402pt입니다.
- 뒷면: PDF의 원형 칼선 자체가 이미 지름 54mm입니다. 이 완성선에서 다시 3mm를 잘라 48mm로 줄이지 않습니다. 3D에 적용할 때만 칼선의 자홍색 선을 제외합니다.
- 목록의 384px 이미지와 3D의 벡터 추출 영역은 같은 완성선 좌표를 사용합니다.
- SVG가 투명한 곳은 원본 인쇄 용지에 맞는 흰 바탕으로 채운 뒤 텍스처로 만듭니다. 투명 여백이 검게 보이는 현상을 막습니다.

## 색상과 옆면

앞·뒷면은 조명과 톤 매핑의 영향을 받지 않는 원본 색상 재질을 사용합니다. 텍스처와 화면 출력은 모두 sRGB입니다. 자석층과 종이 가장자리의 조명은 인쇄면의 색상을 바꾸지 않습니다.

처음 열기와 초기화는 기울임 없는 정면입니다. 정투영 카메라와 앞면 안쪽에 맞춘 옆면 반경으로, 정면에서 옆면이 테두리 밖으로 튀어나오지 않도록 했습니다. 회전하거나 ‘옆면·두께’를 선택하면 2mm의 두께를 볼 수 있습니다.

## 검증

`.validation/check-badge-types.py`에서 다음을 확인합니다.

- 중복 8개 배치가 선택 목록에 없는지, 총72개·타입별24개인지
- 타입 필터와 같은 타입 안의 이전/다음 이동
- 모든 앞면 좌표에서 각 방향 재단 폭이 정확히3mm인지
- 골드·스파클·샤이닝의 실제 렌더링과 원본 사본의 색상 비교
- 첫 화면·초기화 정면, 뒷면과 옆면 조작
- 인쇄용 원본 SVG 펼침 보존, PC·모바일 및 `/portfolio/` 경로 동작

원본과 정면 렌더링의 평균 RGB 편향은 대표 3종에서 채널당 2/255 이내였습니다. 픽셀 단위 오차에는 벡터/이미지 렌더러와 리샘플링 차이가 포함됩니다.

## 대표 배지와 표시 속도

대표 배지는 골드48번·스파클07번·샤이닝06번의 하츄핑을 사용합니다. 목록과 인쇄면의 재단 좌표는 그대로 유지합니다.1024/2048px 인쇄면을 미리 준비하고, 클릭 시 작은 원본 미리보기로3D를 먼저 그린 뒤 선명한 인쇄면으로 교체합니다. 첫 화면을 그리기 위해 전체PDF/SVG의 다운로드와 변환을 기다리지 않습니다. 큰 확대와 제작 원본 보기에서는 원본 벡터를 계속 사용합니다.
